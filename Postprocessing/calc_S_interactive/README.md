# Postprocessing with calc_S_interactive.m

`calc_S_interactive.m` was intended to be an interim solution to implement postprocessing analysis of our quantified peak-shift data (quantified using RetrospectiveAnalysis) from bulk refractive index sensitivity measurement experiments.
The script was designed to take in a list of bulk refractive index solutions and measurements, as well as a bulk RI measurement peak shift dataset, and quantify the bulk refractive index sensitivity of each measured sensor.

Instructions for how to run the script are available on Google Drive [here](https://docs.google.com/document/d/1ZnZOfVhgdjHBoQHI_brZgmlf1tuwcdjdZYl3sOpNYV4/edit?usp=sharing). Example files are available on Google Drive [here](https://drive.google.com/drive/folders/13Zpec7pKYw3S6NezoRcgR_xnjNhJ0fRX?usp=share_link).
